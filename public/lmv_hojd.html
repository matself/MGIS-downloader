Ladda ner Höjddata (Markhöjdmodell)

Här kan du ladda ner Markhöjdmodell (Laserdata). Dessa filer är ofta i .tif format. Du kan välja att ladda ner för hela Sverige (alla filer) eller rita ett område i kartan.
Ange Geotorget-konto nedan (valfritt). Används automatiskt som fallback om Bearer-token nekas av nedladdningsservern (dl1) för ett specifikt dataset.
Geotorget systemkonto — skapa på geotorget.lantmateriet.se. Kom ihåg att beställa de dataset du vill ladda ner.

API Manager Bearer token — generera på apimanager.lantmateriet.se. Token används mot STAC-katalogen och dl1 när det stöds. Fyll i Geotorget-konto (valfritt) för automatisk fallback om Bearer nekas av dl1.

OBS: Du måste ha beställt datasetet i Geotorget för att nedladdningen ska fungera — även för öppna data.

Om du väljer ett län används dess gräns i stället för ritad polygon.
